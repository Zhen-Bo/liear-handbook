# Deletion principles and writing rules

## Source

- [Everyday Astronaut — Starbase Tour and Interview with Elon Musk](https://everydayastronaut.com/starbase-tour-and-interview-with-elon-musk/), Musk’s Engineering Philosophy section.
- Source type: an interview summary published by the original interviewer.
- Verified: 2026-09-12.

## Core concepts

The interview summary presents this sequence: question requirements, delete parts or processes, simplify and optimize, accelerate cycle time, and finally automate.
Each retained item should have an identifiable requester and rationale; possible usefulness alone does not justify keeping it.
The article uses the need to add some deleted items back as a reminder to delete aggressively.

The following applies that engineering process to writing; it is not Musk’s own advice on writing issues.

## Comparison with existing rules

| Existing gap | Improvement |
|---|---|
| Necessity is mentioned without a decision criterion. | Every paragraph must help readers understand the goal, assess the result, or take concrete action; delete it if its purpose cannot be explained. |
| Headings and lists are adjusted first. | Delete unnecessary content before choosing structure and wording for what remains. |
| Unperformed work is retained for completeness. | Completion records list only actual work. Omission does not imply completion, so individual negative statements are unnecessary. |
| Routine unperformed work is moved into limitations. | Retain only observed differences, blockers, or risks that affect judgment, and explain their impact. |
| The same stock phrases recur. | Remove the template rules that generate them so they are not recreated next time. |
| Deletion raises concerns about incomplete information. | Judge whether readers can understand and act; restore necessary information when a specific gap appears. |

## Adoption boundaries

- Do not set a text deletion quota or turn the engineering process’s add-back ratio into a writing metric.
- Delete unnecessary content while retaining required evidence, completion criteria, and actual problems.
- State the verification method and scope directly, such as “checked against official documentation,” so readers can assess the strength of the evidence.
